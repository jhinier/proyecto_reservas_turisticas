# Imágenes pendientes

## 1.1. Identificar tu rol
Página de inicio con el logotipo de La Candelaria, el menú público y los accesos para iniciar sesión o registrarse.

## 1.3. Recuperar la contraseña
Pantalla de recuperación con el campo de correo y el botón para enviar el enlace; otra captura opcional del formulario de nueva contraseña.

## 2.2. Consultar sitios, actividades y festividades
Listado de sitios turísticos con sus tarjetas. Como imágenes complementarias, coloca el listado de actividades y el de festividades.

## 2.3. Consultar el mapa turístico
Mapa turístico con un marcador seleccionado, el buscador de atractivos y los filtros de categorías visibles.

## 2.4. Buscar emprendimientos y servicios
Buscador de servicios con la búsqueda, filtros de categoría y una tarjeta de emprendimiento de demostración.

## 2.5. Seleccionar fechas y preparar el carrito
Página de servicios de un emprendimiento con filtros de fecha, una habitación de demostración y el carrito lateral.

## 2.6. Enviar la solicitud de reserva
Resumen de reserva o checkout con servicios, fechas, total y botón Confirmar reserva; utiliza una reserva de ejemplo sin datos personales reales.

## 2.7. Consultar reservas y enviar un comprobante
Historial del turista con reservas de distintos estados. Imagen complementaria: detalle de una reserva Confirmada con el campo para subir el comprobante.

## 2.8. Cancelar una reserva
Detalle de una reserva con la opción Cancelar y el cuadro para escribir el motivo de cancelación.

## 3.8. Consideraciones sobre la gestión de usuarios
Si el módulo está habilitado, captura Usuarios Registrados mostrando solo cuentas de demostración y sus roles.

## 5.1. Mantener tu perfil y proteger el acceso
Configuración de perfil con datos de demostración y el menú de opciones personales.
